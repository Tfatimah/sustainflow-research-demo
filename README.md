# SustainFlow Agent — Research Demo

Interactive, self-contained mock agent for sustainable process intelligence.

## What it demonstrates
- Existing-system connector concept (ERP, IoT, workflow, database)
- Local CSV preview and canonical event schema
- Observed business process + Kanban WIP/flow view
- Flow metrics, muda/mura and waste tags
- Carbon, energy, rework/waste and synthetic wellbeing signals
- Evidence-based AI Process Agent
- Human approve/modify/reject decision point
- Experiment simulation and Research Notebook
- Architecture designed to extend later with real APIs and event streams

## Important
Default operational and sustainability values are synthetic. The demo is intentionally explicit about observation vs hypothesis vs causality.

Open `index.html` directly in a browser. No server is required.
