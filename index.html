Why this demo exists

SustainFlow explores how process-event data, Kanban flow metrics and IoT-derived sustainability signals can be combined to support process redesign with human oversight.

Objective → Indicator → Sensor → Process context → Agent hypothesis → Human-approved experiment
Agent loop

2. Diagnose

3. Recommend

AI Process Agent
Observation
Packing is the strongest joint flow + sustainability anomaly in the current window.
Evidence
Average WIP 5.8 against policy 3; median work-item age +34%; idle-energy +21%; energy/order +16%; rework events concentrated in the same activity.
Hypothesis
Queue accumulation and uneven arrivals may be increasing waiting, repeated handling and idle-machine energy. This is a hypothesis, not a causal conclusion.
Intervention
Test a lower Packing WIP policy and smaller release batch for one controlled window.
Trade-off
Potential energy and age reduction, with a possible short-term throughput decrease if upstream release is not adjusted.
Limitation
Current demo uses synthetic IoT and process data. Results indicate patterns only and should be validated with real operational data.
